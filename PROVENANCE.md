# Sources and references

This repository contains a Home Manager module, Emacs Lisp configuration,
examples, and tests. It configures external packages through their public APIs;
no package implementations are vendored. The flake lockfile pins Nixpkgs and
Home Manager revisions. Dependencies retain their own licenses.
